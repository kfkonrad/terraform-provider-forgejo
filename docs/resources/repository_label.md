# Resource (forgejo_repository_label)

Forgejo repository label resource. Manages issue/PR labels on a repository.

## Example Usage

### Provider Configuration

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to attach labels to
resource "forgejo_repository" "example" {
  name      = "label_demo_repo"
  auto_init = true
}
```

### Basic Label

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to attach labels to
resource "forgejo_repository" "example" {
  name      = "label_demo_repo"
  auto_init = true
}

# Basic issue label
resource "forgejo_repository_label" "bug" {
  repository  = forgejo_repository.example.full_name
  name        = "bug"
  color       = "d73a4a"
  description = "Something isn't working"
}
```

### Triage Labels

```terraform
# Multiple labels for triage workflow
resource "forgejo_repository_label" "enhancement" {
  repository  = forgejo_repository.example.full_name
  name        = "enhancement"
  color       = "a2eeef"
  description = "New feature or request"
}

resource "forgejo_repository_label" "good_first_issue" {
  repository  = forgejo_repository.example.full_name
  name        = "good first issue"
  color       = "7057ff"
  description = "Good for newcomers"
}
```

## Schema

### Required

- `color` (String) 6-digit hex color of the label, without a leading `#` (e.g. `d73a4a`). Forgejo stores colors in this canonical form.
- `name` (String) Label name.
- `repository` (String) Repository name in format 'owner/repo'.

### Optional

- `description` (String) Description of the label.

### Read-Only

- `id` (Number) Numeric identifier of the label.
- `owner` (String) Owner of the repository.

## Import

Repository labels can be imported using the repository owner, repository name, and the numeric label ID in the format `owner:repo:id`.

```shell
terraform import forgejo_repository_label.bug my-org:my-repo:42
```
