# Resource (forgejo_repository_branch_rule)

Forgejo repository branch rule resource. Manages branch protection rules for repositories.

## Example Usage

### Provider Configuration

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to protect with branch rules
resource "forgejo_repository" "example" {
  name      = "branch_rule_demo_repo"
  auto_init = true
}
```

### Basic Branch Rule

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to protect with branch rules
resource "forgejo_repository" "example" {
  name      = "branch_rule_demo_repo"
  auto_init = true
}

# Basic branch rule protecting the main branch
resource "forgejo_repository_branch_rule" "main" {
  repository               = forgejo_repository.example.full_name
  protected_branch_pattern = "main"
  enable_push              = true
}
```

### Advanced Branch Rule (Full Protections)

```terraform
# Advanced branch rule with full protections
resource "forgejo_repository_branch_rule" "strict" {
  repository               = forgejo_repository.example.full_name
  protected_branch_pattern = "release/**"

  # Push restrictions
  enable_push              = true
  enable_push_whitelist    = true
  push_whitelist_usernames = ["release-manager"]
  push_whitelist_teams     = ["release-team"]

  # Require approvals
  required_approvals            = 2
  enable_approvals_whitelist    = true
  approvals_whitelist_usernames = ["lead-dev", "senior-dev"]
  dismiss_stale_approvals       = true

  # Status checks
  enable_status_check   = true
  status_check_contexts = ["ci/build", "ci/test"]

  # Merge restrictions
  enable_merge_whitelist            = true
  merge_whitelist_usernames         = ["release-manager"]
  block_on_rejected_reviews         = true
  block_on_official_review_requests = true
  block_on_outdated_branch          = true

  # File protection
  protected_file_patterns   = "LICENSE;go.mod;go.sum"
  unprotected_file_patterns = "docs/**"
}
```

## Schema

### Required

- `protected_branch_pattern` (String) Protected branch name pattern (e.g. `main`, `release/**`).
- `repository` (String) Repository name in format 'owner/repo'.

### Optional

- `approvals_whitelist_teams` (Set of String) Whitelisted teams for reviews.
- `approvals_whitelist_usernames` (Set of String) Whitelisted reviewers.
- `block_on_official_review_requests` (Boolean) Block merge on official review requests. Defaults to `false`.
- `block_on_outdated_branch` (Boolean) Block merge if pull request is outdated. Defaults to `false`.
- `block_on_rejected_reviews` (Boolean) Block merge on rejected reviews. Defaults to `false`.
- `dismiss_stale_approvals` (Boolean) Dismiss stale approvals when new commits are pushed. Defaults to `false`.
- `enable_approvals_whitelist` (Boolean) Restrict approvals to whitelisted users or teams. Defaults to `false`.
- `enable_merge_whitelist` (Boolean) Enable merge whitelist. Defaults to `false`.
- `enable_push` (Boolean) Enable push to the protected branch. Defaults to `false`.
- `enable_push_whitelist` (Boolean) Whitelist restricted push. Defaults to `false`.
- `enable_status_check` (Boolean) Enable status check. Defaults to `false`.
- `merge_whitelist_teams` (Set of String) Whitelisted teams for merging.
- `merge_whitelist_usernames` (Set of String) Whitelisted users for merging.
- `protected_file_patterns` (String) Protected file patterns (semicolon-separated glob patterns). Defaults to `""`.
- `push_whitelist_deploy_keys` (Boolean) Whitelist deploy keys with write access to push. Defaults to `false`.
- `push_whitelist_teams` (Set of String) Whitelisted teams for pushing.
- `push_whitelist_usernames` (Set of String) Whitelisted users for pushing.
- `require_signed_commits` (Boolean) Require signed commits. Defaults to `false`.
- `required_approvals` (Number) Number of required approvals. Defaults to `0`.
- `status_check_contexts` (Set of String) Status check patterns.
- `unprotected_file_patterns` (String) Unprotected file patterns (semicolon-separated glob patterns). Defaults to `""`.

### Read-Only

- `branch_name` (String) The branch name matched by this rule.
- `created_at` (String) Timestamp of when the branch rule was created.
- `owner` (String) Owner of the repository.
- `updated_at` (String) Timestamp of when the branch rule was last updated.

## Import

Repository branch rules can be imported using the repository owner, repository name, and the protected branch name pattern in the format `owner:repo:pattern`.

```shell
terraform import forgejo_repository_branch_rule.release my-org:my-repo:release/**
```
