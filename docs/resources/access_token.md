# Resource (forgejo_access_token)

Forgejo access token resource. Manages personal access tokens for API authentication.

With basic auth (`username`/`password`), the provider manages tokens via `/users/{username}/tokens`, which works for the authenticated user and, for site administrators, for any user. With API token auth (`api_token`), it uses the admin API `/admin/users/{username}/tokens` instead, because Forgejo does not allow creating tokens with another token on the regular route. This requires Forgejo 16 or newer and a site administrator token with the `write:admin` scope.

## Example Usage

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# User
resource "forgejo_user" "test" {
  username = "testuser"
  email    = "testuser@example.com"
  password = "testpass123"
}

# Access token
resource "forgejo_access_token" "this" {
  username = forgejo_user.test.username
  name     = "my_api_token"
  scopes   = ["repo", "write:org"]
}

# Access token limited to specific repositories
resource "forgejo_access_token" "scoped" {
  username     = forgejo_user.test.username
  name         = "my_scoped_token"
  scopes       = ["read:repository"]
  repositories = ["testuser/some_repo"]
}
```

### Required

- `name` (String) Name of the access token.
- `scopes` (Set of String) Set of scopes for the access token. Allowed values:
  - `all`
  - `public-only`
  - `sudo`
  - `read:activitypub`
  - `write:activitypub`
  - `read:admin`
  - `write:admin`
  - `read:issue`
  - `write:issue`
  - `read:misc`
  - `write:misc`
  - `read:notification`
  - `write:notification`
  - `read:organization`
  - `write:organization`
  - `read:package`
  - `write:package`
  - `read:repository`
  - `write:repository`
  - `read:user`
  - `write:user`
- `username` (String) Username of the user to create the token for. This explicitly specifies which user owns the token.

### Optional

- `repositories` (Set of String) Set of repositories (`owner/name`) the token is limited to. When unset, the token has access to every repository the user can access. Requires Forgejo 15 or newer.

### Read-Only

- `id` (Number) Numeric identifier of the access token.
- `token` (String, Sensitive) The actual access token value. This is only available when the token is first created and cannot be retrieved later.
