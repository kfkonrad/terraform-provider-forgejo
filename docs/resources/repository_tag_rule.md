# Resource (forgejo_repository_tag_rule)

Forgejo repository tag rule resource. Manages tag protection rules for repositories.

## Example Usage

### Provider Configuration

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to protect with tag rules
resource "forgejo_repository" "example" {
  name      = "tag_rule_demo_repo"
  auto_init = true
}
```

### Basic Tag Rule

```terraform
terraform {
  required_providers {
    forgejo = {
      source = "kfkonrad/forgejo"
    }
  }
}

provider "forgejo" {
  host = "http://localhost:3000"
}

# Repository to protect with tag rules
resource "forgejo_repository" "example" {
  name      = "tag_rule_demo_repo"
  auto_init = true
}

# Basic tag rule protecting version tags
resource "forgejo_repository_tag_rule" "versions" {
  repository            = forgejo_repository.example.full_name
  protected_tag_pattern = "v*"
}
```

### Advanced Tag Rule (Whitelist Restrictions)

```terraform
# Advanced tag rule with whitelist restrictions
resource "forgejo_repository_tag_rule" "releases" {
  repository            = forgejo_repository.example.full_name
  protected_tag_pattern = "release/**"

  # Only allow specific users and teams to create matching tags
  whitelist_usernames = ["release-manager"]
  whitelist_teams     = ["release-team"]
}
```

## Schema

### Required

- `protected_tag_pattern` (String) Protected tag name pattern (e.g. `v*`, `release/**`).
- `repository` (String) Repository name in format 'owner/repo'.

### Optional

- `whitelist_teams` (Set of String) Whitelisted teams for creating matching tags.
- `whitelist_usernames` (Set of String) Whitelisted users for creating matching tags.

### Read-Only

- `created_at` (String) Timestamp of when the tag rule was created.
- `id` (Number) Numeric identifier of the tag protection rule.
- `owner` (String) Owner of the repository.
- `updated_at` (String) Timestamp of when the tag rule was last updated.

## Import

Repository tag rules can be imported using the repository owner, repository name, and the numeric tag protection ID in the format `owner:repo:id`.

```shell
terraform import forgejo_repository_tag_rule.release my-org:my-repo:42
```
